# Phone Stress Test — پروژه اندروید

پروژه برای Android 13 / HyperOS طراحی شده است. این فایل‌ها **سورس کد پروژه** هستند و APK کامپایل‌شده نیستند.

## امکانات
- فشار CPU با تعداد هسته قابل انتخاب (تا تعداد هسته‌های قابل مشاهده سیستم)
- تخصیص اختیاری ۰ تا ۲۵۶ مگابایت حافظه برای تست فشار RAM
- نمایش دمای باتری و درصد شارژ
- نمایش وضعیت حرارتی Android در نسخه‌های پشتیبانی‌شده
- سرویس foreground و اعلان دائمی با دکمه «توقف فوری»
- توقف دستی از داخل برنامه یا اعلان
- توقف حفاظتی در دمای باتری ۴۸°C یا وضعیت حرارتی `SEVERE` اندروید

## ساخت APK
1. Android Studio جدید را نصب کنید و SDK Platform 35 و JDK 17 یا جدیدتر را داشته باشید.
2. از Android Studio گزینه **Open** را بزنید و پوشه `PhoneStressTest` را باز کنید.
3. صبر کنید تا Gradle Sync کامل شود.
4. از منوی **Build → Build APK(s)** خروجی بگیرید.
5. APK معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نکات ایمنی و محدودیت‌ها
- تست سنگین CPU گرما و مصرف باتری را بالا می‌برد. گوشی را هنگام تست روی سطح سخت و خنک بگذارید و در صورت داغی غیرعادی، فوراً متوقف کنید.
- دمای نمایش‌داده‌شده، دمای باتری است؛ دسترسی مستقیم به دمای CPU/GPU در همه دستگاه‌ها مجاز یا در دسترس نیست.
- HyperOS ممکن است اجرای پس‌زمینه را محدود کند. اگر سرویس متوقف شد، تنظیمات باتری برنامه را روی حالت بدون محدودیت بگذارید؛ این کار محافظت حرارتی سیستم را غیرفعال نمی‌کند.
- برای جلوگیری از آسیب، برنامه عمداً محافظت حرارتی دارد و توقف حفاظتی را نمی‌توان از داخل برنامه خاموش کرد.
